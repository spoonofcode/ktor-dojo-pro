# ktor-dojo-pro
Ktor Dojo Pro

LIBRARIES USED:
* Client and server app - Ktor (https://ktor.io/)
* Database - MySQL (https://www.mysql.com/)
* JDBC - HikariCP (https://github.com/brettwooldridge/HikariCP)
* ORM - Exposed (https://www.jetbrains.com/exposed/)
* Depency Injection - Koin (https://insert-koin.io/)
* Notificaiton - Firebase Cloud Messaging (https://firebase.google.com/docs/reference/fcm/rest)
* Password hashing - jbCrypt (https://github.com/jeremyh/jBCrypt)
* Google auth(https://developers.google.com/identity/protocols/oauth2?hl=pl)
